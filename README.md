# モンテイア｜予約管理システム

添付の画面案をもとにした、架空のレストラン「モンテイア」の店内用予約管理システムです。
謎解きは、システムに入る前にロボットでないことを確認するチェックとして表示します。
HTML・CSS・JavaScriptだけで動作し、実際の予約や個人情報を取得・送信しません。

## 画面の流れ

1. 「すすむ」で開始。
2. 「調味料」の左上と左下を選択して「確認」。この2枚だけが正解。
3. 「かけるもの」の4枚をすべて選択して「確認」。
4. 1〜8卓から選択。3卓のみ予約情報を表示。他の卓は閲覧不可のダイアログを表示。
5. 3卓の予約者と備考「『3』と『4』のロウソク準備」を表示。

誤答時は同じ画面に留まり、タイルが短く横に揺れます。
選択は押し直すか「選択を解除」で変更できます。
ブラウザの再読み込み、または「はじめから」で初期化します。

## ファイル

- `dist/index.html`: 共通の画面枠とダイアログ。
- `dist/styles.css`: スマートフォン・PC向けの表示と動きを減らす設定への対応。
- `dist/app.js`: 画面表示、操作、画面遷移。
- `dist/puzzles.mjs`: 正解判定、パネルの参照範囲、予約情報。
- `dist/assets/puzzle-reference.png`: ユーザーが提供した原図。画像自体は改変せず、SVGの表示領域でパネル部分を使用。

予約者名・備考・正解を変更する場合は `dist/puzzles.mjs` を編集してください。
このサイトは演出用です。正解の情報はブラウザ側のソースに含まれます。

## 手元で起動する

このリポジトリのディレクトリで、Python 3 の簡易HTTPサーバーを起動します。

```bash
python3 -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000` を開いてください。
JavaScriptのESモジュールを使うため、HTMLファイルを直接開かず、HTTPサーバー経由で実行します。
依存ライブラリのインストールやビルドは不要です。

静的ホスティングを利用する場合は `dist/` の内容を公開ディレクトリに配置します。
